Bem-vindo ao PetCare

Cuidar bem também é uma forma de amar.

O PetCare é um projeto educativo criado para apresentar informações simples sobre cuidados essenciais com pets e, ao mesmo tempo, ensinar conceitos fundamentais de desenvolvimento web, como HTML semântico, CSS e design responsivo.

Bem-estar animal

Cuidados essenciais

Alguns cuidados básicos fazem parte da rotina de qualquer animal de estimação. Alimentação adequada, higiene, exercícios e acompanhamento veterinário ajudam a manter uma vida mais saudável.

Alimentação

Ofereça uma alimentação equilibrada e adequada à espécie, idade, porte e necessidades do animal.

Higiene

Banhos, escovação, limpeza dos espaços e cuidados com dentes e unhas ajudam a preservar a saúde do pet.

Exercícios

Atividades físicas adequadas ajudam a controlar o peso, reduzir o estresse e estimular o animal.

Consultas veterinárias

O acompanhamento profissional permite prevenir problemas e acompanhar a saúde do animal.

Desenvolvimento web

Aprenda sobre HTML Semântico

HTML semântico utiliza elementos que descrevem claramente o significado e a função de cada parte do conteúdo de uma página.

O que é HTML semântico?

É uma forma de construir páginas utilizando tags que representam o propósito do conteúdo. Em vez de utilizar elementos genéricos para tudo, escolhemos elementos que possuem significado.

Por que utilizar tags semânticas?

Elas melhoram a organização do código, facilitam a manutenção, ajudam mecanismos de busca a compreender o conteúdo e contribuem para a acessibilidade.

  • Melhor organização estrutural.
  • Maior facilidade de manutenção.
  • Melhor interpretação por tecnologias assistivas.
  • Estrutura mais clara para mecanismos de busca.

Principais elementos semânticos

<header>
Representa o cabeçalho de uma página ou de uma seção.
<main>
Representa o conteúdo principal da página.
<section>
Organiza um conteúdo relacionado dentro de uma área.
<article>
Representa um conteúdo independente que pode fazer sentido por si só.
<footer>
Representa o rodapé de uma página ou seção.

Estilização

Aprenda sobre CSS

CSS é a linguagem utilizada para controlar a apresentação visual dos elementos HTML.

O que é CSS?

CSS significa Cascading Style Sheets, ou Folhas de Estilo em Cascata. Ele permite definir cores, tamanhos, espaçamentos, posicionamento, fontes e diversos outros aspectos visuais.

Para que serve?

CSS separa a apresentação visual da estrutura HTML, permitindo que o mesmo documento HTML receba diferentes estilos sem alterar seu conteúdo.

Exemplos de propriedades CSS

  • color Define a cor do texto.
  • background-color Define a cor de fundo de um elemento.
  • font-size Define o tamanho da fonte.
  • margin Controla o espaçamento externo.
  • padding Controla o espaçamento interno.
  • display Define como um elemento participa do layout.

Estrutura x apresentação

O HTML define o significado e a estrutura do conteúdo. O CSS define como esse conteúdo será apresentado visualmente. Essa separação torna o projeto mais organizado e fácil de manter.

Experiência multiplataforma

Design Responsivo

Uma página responsiva adapta seu layout para diferentes tamanhos de tela, proporcionando uma experiência adequada em computadores, tablets e smartphones.

O que é Design Responsivo?

É uma abordagem de desenvolvimento que permite que uma interface se adapte automaticamente ao espaço disponível na tela.

Por que é importante?

Pessoas acessam sites utilizando dispositivos com diferentes resoluções. Uma interface responsiva evita conteúdos cortados, textos difíceis de ler e rolagem horizontal desnecessária.

O que são componentes responsivos?

São elementos da interface capazes de modificar seu tamanho, posição ou organização conforme o espaço disponível. Cards, menus, imagens e grids podem ser responsivos.

O que são breakpoints?

Breakpoints são pontos definidos no CSS onde determinadas regras de estilo são alteradas para adaptar o layout a diferentes larguras de tela.

  • Mobile-first.
  • Grid e Flexbox para layouts flexíveis.
  • Imagens adaptáveis.
  • Media queries para diferentes tamanhos de tela.
