Desenvolvimento web

Aprenda sobre HTML Semântico

Entenda como organizar uma página utilizando elementos que possuem significado.

O que é HTML semântico?

HTML semântico é uma forma de escrever HTML utilizando elementos que descrevem o significado do conteúdo.

Em vez de utilizar somente elementos genéricos como <div>, utilizamos elementos como <header>, <main>, <section>, <article> e <footer>.

Por que utilizar tags semânticas?

  • Melhoram a organização do código.
  • Facilitam a manutenção do projeto.
  • Ajudam mecanismos de busca a compreenderem o conteúdo.
  • Contribuem para uma melhor acessibilidade.

Exemplos de elementos semânticos

<header>
Representa o cabeçalho de uma página ou seção.
<main>
Representa o conteúdo principal da página.
<section>
Agrupa conteúdos relacionados a um mesmo assunto.
<article>
Representa um conteúdo independente e reutilizável.
<footer>
Representa informações finais da página ou seção.

Aprenda sobre CSS

Entenda como transformar uma estrutura HTML em uma interface visualmente organizada.

O que é CSS?

CSS significa Cascading Style Sheets, ou Folhas de Estilo em Cascata.

Ele controla a apresentação visual dos elementos HTML, como cores, fontes, espaçamentos, tamanhos e posicionamento.

Para que serve?

Com CSS podemos criar interfaces organizadas, agradáveis, acessíveis e adaptáveis a diferentes tamanhos de tela.

Exemplos de propriedades CSS

  • color Define a cor do texto.
  • background-color Define a cor de fundo.
  • font-size Define o tamanho da fonte.
  • margin Controla o espaçamento externo.
  • padding Controla o espaçamento interno.
  • display Controla como um elemento é apresentado.

Estrutura x apresentação

O HTML é responsável principalmente pela estrutura e significado do conteúdo. O CSS é responsável pela apresentação visual.

Experiência do usuário

Design Responsivo

Uma interface deve funcionar bem em diferentes dispositivos e tamanhos de tela.

O que é Design Responsivo?

Design Responsivo é uma abordagem que permite que uma página se adapte a diferentes tamanhos de tela.

A mesma interface pode ser utilizada em smartphones, tablets, notebooks e monitores maiores.

Por que é importante?

As pessoas acessam a internet utilizando diferentes dispositivos. Uma interface responsiva proporciona uma experiência mais consistente.

O que são componentes responsivos?

São elementos capazes de modificar seu tamanho, posicionamento ou organização de acordo com o espaço disponível.

O que são breakpoints?

Breakpoints são pontos definidos no CSS em que o layout pode mudar para se adaptar a diferentes larguras de tela.

Eles são normalmente implementados utilizando @media queries.
